# Shortcuts and gestures

## On the desk

| Keys | Does |
|---|---|
| ⌘1 | Apps |
| ⌘K | Search the desk and the hub |
| ⌘W | Close the front window |
| ⌘R | Restart the running eggs |
| ⌘, | Settings |
| ⌘Q | Quit, shutting eggs down first |

## In an egg's window

| Keys | Does |
|---|---|
| ⌘V | Paste your clipboard into the egg |
| ⌘C | Copy a value from the About panel (click it first) |
| Control-Option-+ / - | Zoom the window in or out |
| Control-Option-0 | Back to one pixel per pixel |
| Control-⌘F | Full screen |
| ⌘ alone | Reaches the egg as Super: the app overview in Sandbox and Ubuntu |

Everything else you type goes to the egg, with the Mac keys mapped to their Linux names: Option is Alt, ⌘ is Super.

## Trackpad

- **Two-finger scroll** scrolls inside the egg, in any app.
- **Click with two fingers** is a right-click inside the egg.
- Pinch, three-finger swipes and Mission Control gestures belong to the Mac; the egg never sees them. Use the egg's own keys instead: Super for the overview, Super-Tab to switch apps.
