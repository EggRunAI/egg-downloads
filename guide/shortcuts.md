# Keyboard shortcuts

| Keys | Does |
|---|---|
| ⌘1 | Apps |
| ⌘K | Search |
| ⌘W | Close the front window |
| ⌘R | Restart the running eggs |
| ⌘, | Settings |
| ⌘Q | Quit, shutting eggs down first |

Inside an egg's window, your keyboard belongs to the egg. Press **⌘** to give it back to the Mac.
