# Agents and the egg

An egg is a safe place to let an AI agent work: whatever it installs, downloads or breaks stays inside the egg, and the egg can be thrown away.

## Agents inside the egg

Diamond Linux ships **Claude** and **Codex**, as desktop apps and as the **Claude CLI** and **Codex CLI** on the dock. Click one, sign in with your own account, and ask for something. See **Vibe coding in Diamond**.

## Your Mac's agent, driving the egg

Egg runs an MCP server on your Mac, so an agent you already use (Claude Desktop, Claude Code, Codex, any MCP client) can start eggs, type into them, read their screens, run commands in them and take snapshots. The **MCP** button in an egg's window shows the one line to add to your agent's settings, and lists the agents currently connected.

## What the egg lets an agent do

The guest agent inside each egg answers questions from your Mac: processes, files, network, system facts, and it sets the clock after a resume. It does not run commands by itself and it only answers the machine that runs the egg.
